# Data Analytics and Visualization (DAV) Lab Experiments

This repository contains the laboratory experiments completed for the **Data Analytics and Visualization (DAV)** course as part of the Computer Science and Engineering curriculum.

## 📚 About

The aim of this repository is to provide implementations of various data analytics and visualization techniques using Python and Jupyter Notebook. These experiments demonstrate how to collect, process, analyze, and visualize data to extract meaningful insights.

## 📂 Repository Structure

```
Labexperiment/
│
├── experiment1/
├── experiment2/
├── experiment3/
├── ...
```

Each experiment includes:
- Problem Statement
- Source Code
- Dataset (if applicable)
- Output/Visualization
- Observations

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Dhiva-alt/lab_experiments.git
```

2. Open the required experiment in **Jupyter Notebook** or **Visual Studio Code**.

3. Install the required libraries if needed:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

4. Run the notebook cells sequentially.
